## Descrição

Atividade prática sobre concorrência em linguagens de programação, abordando condições de corrida, sincronização de threads, deadlock, canais de comunicação e laço de eventos.

Foram utilizados exemplos em Java, Python, Go, Rust e JavaScript para entender como cada linguagem trabalha com concorrência e quais problemas podem acontecer durante a execução.
